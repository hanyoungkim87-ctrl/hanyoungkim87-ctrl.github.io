DESIGN NOTES

What this demo compares

01

A shared starting point

Everyone copies and pastes the same assigned shopping request. All conditions show the same products in A–B–C order, the same prices, and the same initial recommendation: Product B.

02

Explanation, then source control

No explanation shows the product recommendations alone. Static and interactive conditions share the same initial source explanation and 50:50 weights. Only the interactive condition adds an optional slider and Update recommendations button.

03

A responsive source-weight model

The two sources are request match and overall product information and review evaluation—not battery versus sound. Request weights of 75%, 50%, and 25% recommend A, B, and C. Any product can be selected without adjusting the weights.

Design review demo · v2026-10-21-readable-v3. Products, specifications, ratings, and source scores are fictional. The source scores are assigned for this fixed scenario; no live reviews are retrieved, no free-text interpretation is performed, and no AI model is used. Scores are A: 9/6, B: 8/8, C: 6/9 for request fit / overall external evaluation. This is a three-condition design, not a full factorial experiment.
